# Skills

这里放 IntentFlow 的 superpower、workflow 和可复用规则。

## 入口

- [superpowers](./superpowers/README.md)：长期可复用能力规则。
- [personal-grill-me](./personal-grill-me/SKILL.md)：产品想法和方案的前置决策澄清。
- [demand-evidence-research](./demand-evidence-research/SKILL.md)：按需核验用户痛点、竞品和产品机会，并记录可追溯来源。
- [product-prd](./product-prd/SKILL.md)：把已澄清的产品选择写成可评审、可校验的 Markdown PRD。
- [product-prototype](./product-prototype/SKILL.md)：把已定需求表达为可操作原型，并核对页面与状态。
- [product-flows](./product-flows/SKILL.md)：绘制业务、页面、状态与按需时序流程，并检查一致性。
- [product-acceptance](./product-acceptance/SKILL.md)：从需求和原型生成可执行的功能验收清单并记录结果。
- [product-analytics](./product-analytics/SKILL.md)：用真实数据做可复算的指标、漏斗和迭代分析。
- [figma-build](./figma-build/SKILL.md)：把代码、需求或描述落到 Figma，并复用已有设计系统。
- [figma-codegen](./figma-codegen/SKILL.md)：把 Figma 设计转成贴合项目技术栈的代码。
- [workflows](./workflows/)：工作流复盘、导入审核和执行规则。
- [local-codex-skills](./local-codex-skills/)：本地 Codex skill。
