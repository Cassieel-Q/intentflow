# Skills

这里放 IntentFlow 的 superpower、workflow 和可复用规则。

## 入口

- [superpowers](./superpowers/README.md)：长期可复用能力规则。
- [personal-grill-me](./personal-grill-me/SKILL.md)：产品想法和方案的前置决策澄清。
- [figma-build](./figma-build/SKILL.md)：把代码、需求或描述落到 Figma，并复用已有设计系统。
- [figma-codegen](./figma-codegen/SKILL.md)：把 Figma 设计转成贴合项目技术栈的代码。
- [workflows](./workflows/)：工作流复盘、导入审核和执行规则。
- [local-codex-skills](./local-codex-skills/)：本地 Codex skill。
