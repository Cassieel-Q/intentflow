# Reusable Workflow Skills

These skills are project-neutral building blocks for AI-assisted engineering.

## Available skills

- [api-contract-discipline](./api-contract-discipline.md): API fields, errors,
  display names, and validation.
- [design-doc-sync](./design-doc-sync.md): keeping design and implementation
  records aligned.
- [evidence-backed-grilling](./evidence-backed-grilling.md): resolve
  consequential ambiguity with evidence.
- [systematic-debugging](./systematic-debugging.md): reproduce, isolate, fix,
  and regress-check failures.
- [tdd-red-green-refactor](./tdd-red-green-refactor.md): apply TDD according
  to change risk.
- [verification-gate](./verification-gate.md): choose proportionate checks.
- [frontend-reuse-and-path-verification](./frontend-reuse-and-path-verification.md):
  verify user-visible frontend paths.
- [figma-to-real-feature](../local-codex-skills/figma-to-real-feature/SKILL.md):
  turn design input into maintainable UI.

Use only the skills relevant to the current task. Keep project-specific
instructions in private project storage.
