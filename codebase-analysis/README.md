# Codebase Analysis

This directory is an optional place for reusable, project-neutral analysis
notes.

## Suggested structure

```text
codebase-analysis/
  README.md
  repos/<repository-name>/
  cross-cutting/<topic>/
```

Keep analysis evidence concise, traceable, and safe to publish. Do not place
private source code, credentials, internal URLs, customer data, or
project-specific business facts in a public repository.
