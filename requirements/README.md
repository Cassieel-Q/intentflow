# Requirements

This directory contains reusable requirement templates and decision records for
IntentFlow projects.
Each project may keep its own requirement directory in private storage.

## Rules

- Separate source material from confirmed decisions.
- Keep open questions visible until resolved.
- Record interface, data, state, validation, and risk changes explicitly.
- Link evidence instead of copying large implementation details.
- Add a final-review proposal before final acceptance.

See [common](./common/README.md) for shared templates and workflow guidance.
